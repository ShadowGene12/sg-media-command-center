## 2024-07-08 - Authentication Bypass in Supabase Edge Functions
**Vulnerability:** The `create-checkout-session` edge function previously accepted `userId` and `email` directly from the client request body without validating the identity of the user via the provided authorization JWT, creating an Authentication Bypass and Insecure Direct Object Reference (IDOR) vulnerability.
**Learning:** Supabase edge functions don't automatically verify JWTs passed in headers. Developers must manually fetch the verified user identity via `supabaseClient.auth.getUser()`. Trusting unverified client input allows a malicious actor to perform sensitive operations on behalf of another user.
**Prevention:** In Supabase Edge Functions, always inject the JWT from the `Authorization` header into the global headers of `createClient()`, and retrieve user details securely using `await supabaseClient.auth.getUser()`. Never rely on `userId` or `email` provided in the request payload for sensitive operations.
