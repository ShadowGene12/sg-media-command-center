## 2024-03-21 - Supabase Edge Function Insecure Direct Object Reference (IDOR) & Auth Bypass
**Vulnerability:** Supabase Edge Function (`create-checkout-session`) trusted client-provided `userId` and `email` from the HTTP request body instead of cryptographically verifying the user identity from the `Authorization` header JWT. This would allow an attacker to bypass authentication and create subscriptions for arbitrary users (IDOR/Auth Bypass).
**Learning:** In Supabase Edge Functions, JWTs sent in the `Authorization` header are **not automatically verified or enforced** by default. Functions must explicitly instantiate a Supabase client using the incoming `Authorization` header and call `supabase.auth.getUser()` to verify the token and establish the true identity of the requester.
**Prevention:** Always use `createClient` passing the incoming `Authorization` header and use `supabase.auth.getUser()` in Edge Functions to securely identify the caller. Never trust client-provided IDs or emails for sensitive operations like payment processing or data modification.
