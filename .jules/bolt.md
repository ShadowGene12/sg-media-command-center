## 2026-07-07 - Zustand Selector Optimization
**Learning:** In the command-center React app, components like `AppSidebar`, `AppHeader`, `HomeDashboard`, etc. frequently use the `useCommandStore()` hook without state selectors. This pattern subscribes the component to the entire Zustand store, causing unnecessary re-renders whenever ANY state in the store changes, even if the component doesn't use that specific state. This is a common performance bottleneck in React apps using Zustand.
**Action:** Refactor instances of `useCommandStore()` to use individual state selectors (e.g., `useCommandStore(state => state.property)`). I should use multiple individual selector calls rather than assuming `useShallow` is available or necessary, to prevent unnecessary application shell re-renders.
